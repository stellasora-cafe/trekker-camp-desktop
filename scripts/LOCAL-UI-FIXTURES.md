# 本地 UI 验收数据

在仓库根目录运行：

```powershell
node scripts/seed-local-ui.mjs
```

脚本固定访问 `http://localhost:3000`，通过现有 API 添加数据。需要本地服务已启动，且 `artifacts/local-account.json` 中的 `campdev` 管理员会话有效。脚本保留该文件与原登录会话，不修改数据库、不删除已有内容。

首次运行会建立或复用以下本地账号：

- `campdev`：原管理员账号，原生客户端与 WebView 性能对照共用。
- `campqa`：双向心链、群聊和帖子互动的同伴；有一个待接受关注请求。
- `camprequest`：仅用于待接受关注请求和发现页投票的辅助账号。

密码及独立的网页、桌面会话保存在 `artifacts/local-ui-accounts.json`。网页使用 `webSession`，原生客户端使用 `session`；也可在对应 UI 中使用账号密码登录。凭据文件不要提交、输出到日志或附入报告。

数据包含普通帖、长文展开、CW、MFM、图片、公开和指定可见内容、回复与引用、进行中及已结束投票；心链包含双方文字消息、图片附件、双方群聊消息和待接受群聊邀请。普通展示角色没有管理权限，通知测试令牌权限为空。定时失败样本在投票过期后发布，保留失败草稿用于恢复操作验收。双方通知列表合计覆盖当前 20 种通知类型。

输出文件均位于被 Git 忽略的 `artifacts/`：

| 文件 | 用途 |
| --- | --- |
| `local-ui-report.json` | 不含凭据的账号 ID、帖子 URL、聊天路径、通知覆盖、热门列表及本次写 API 调用 |
| `local-ui-seed-state.json` | 已创建对象 ID 与已完成步骤；继续验收时保留，避免重放通知、导出和授权操作 |
| `local-ui-accounts.json` | 本地账号凭据与各客户端会话，仅供本机测试工具读取 |
| `local-ui-idempotency.json` | 重复运行验证结果，包含对象数量、零写 API 调用与原登录未变检查 |

脚本按可识别前缀 `[本地 UI 验收]` 和状态文件复用数据；重复运行保留已有 ID。请保留状态文件与账号文件。API 验证会读取双方聊天时间线，因此相应消息会变为已读；通知读取使用 `markAsRead: false`。

发现页投票应使用报告中“发现页投票”的 URL。推荐接口过滤当前账号自己发布或已经投过的投票，因此先完成两端截图，再执行投票。热门列表采用服务端抽样排名及缓存，报告记录实际返回的数据。交互验收可以改变关注、邀请和投票状态；脚本保留这些操作结果，不撤销用户测试。

本地验收通过：双方私聊与群聊消息及历史一致、投票具有真实票数、全部通知类型可读取；重复运行发送零条写 API 请求，既有帖子、房间、消息、草稿和令牌的 ID 与数量保持一致，原 `campdev` 凭据文件保持原样。
